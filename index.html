Practical 1: Two Subnets Network Design Using NetSim

Aim: To design and simulate a network scenario consisting of two subnets connected via a router in NetSim, and to study the traffic flow from Node 4 (Subnet 1) to Node 3 (Subnet 2).

1. Topology & IP Configuration

  • Subnet 1 (192.168.1.0/24): 6 Wired Nodes (N1–N6: 192.168.1.2 to 192.168.1.7) connected via Switch 1 to Router Interface 1 (192.168.1.1). Gateway: 192.168.1.1.
  • Subnet 2 (192.168.2.0/24): 5 Wired Nodes (N1–N5: 192.168.2.2 to 192.168.2.6) connected via Switch 2 to Router Interface 2 (192.168.2.1). Gateway: 192.168.2.1.

2. Procedure

  1. Open NetSim → New Simulation → Internetworks.
  2. Place 11 Wired Nodes, 2 Switches, and 1 Router. Connect Subnet 1 devices to Switch 1 and Router Interface 1. Connect Subnet 2 devices to Switch 2 and Router Interface 2.
  3. Assign IP addresses, subnet masks (255.255.255.0), and default gateways according to the configuration plan.
  4. Configure application traffic: Source: Node 4 (Subnet 1, 192.168.1.5) → Destination: Node 3 (Subnet 2, 192.168.2.4). Use CBR/UDP with packet size 512 bytes, inter-arrival time 10,000 μs.
  5. Enable Packet Trace, run the simulation, and inspect path metrics.

3. Traffic Flow

Node 4 (Subnet 1) → Switch 1 → Router (192.168.1.1 → 192.168.2.1) → Switch 2 → Node 3 (Subnet 2)

4. Observations

ParameterObservation
DeliveryPackets successfully reach Node 3 across the boundary.
Path TraverseCrosses L2 switches and requires L3 routing across interfaces.
Delay ProfileIncludes queuing, transmission, propagation, and router processing delays.

5. Inference

Devices across different subnets cannot communicate via L2 switching alone and require a default gateway (Router) to route packets across subnet boundaries based on IP destination lookups.

Practical 2: Traffic Generation Rate and Service Rate in NetSim

Aim: To study the relationship between traffic generation rate and bottleneck link service rate, and analyze their impact on packet drops, delay, and queuing.

Formula

Generation Rate (Mbps) = (Packet Size in Bytes × 8) / Inter-arrival Time (μs)

Procedure

  1. Create a source-destination path with a constrained bottleneck link (e.g., 10 Mbps).
  2. Vary packet size (e.g., 512B, 1000B, 1500B) and inter-arrival time (e.g., 500 μs to 10,000 μs).
  3. Execute runs and record throughput, average delay, queue length, and dropped packets.

Observations & Inference

  • Generation Rate < Service Rate: Queues remain stable and clear quickly; throughput matches generation rate with minimal latency.
  • Generation Rate ≈ Service Rate: Buffer queuing rises sharply; queuing delay increases significantly.
  • Generation Rate > Service Rate: Bottleneck capacity is exceeded; queues overflow causing packet drops and maximum latency.

Practical 3(a): Hostname, IP Address, Class, Network ID & Host ID

Aim: Write a C++ program to fetch the computer's hostname and IPv4 address, identify its class, and print Network and Host IDs.

Code (hostname.cpp)

#include <iostream>
#include <cstdio>
#include <string>
#include <winsock2.h>

using namespace std;

int main() {
    WSADATA wsa;
    WSAStartup(MAKEWORD(2, 2), &wsa);

    char name[256];
    gethostname(name, sizeof(name));
    cout << "Hostname: " << name << endl;

    hostent *h = gethostbyname(name);
    if (h == NULL || h->h_addr_list[0] == NULL) {
        cout << "IPv4 address not found\n";
        WSACleanup();
        return 1;
    }

    in_addr addr = *(in_addr *)h->h_addr_list[0];
    string ip = inet_ntoa(addr);
    cout << "IPv4 Address: " << ip << endl;

    int a, b, c, d;
    sscanf(ip.c_str(), "%d.%d.%d.%d", &a, &b, &c, &d);

    if (a >= 1 && a <= 126) {
        cout << "Class: A\nNetwork ID: " << a << ".0.0.0\nHost ID: " << b << "." << c << "." << d << endl;
    } else if (a >= 128 && a <= 191) {
        cout << "Class: B\nNetwork ID: " << a << "." << b << ".0.0\nHost ID: " << c << "." << d << endl;
    } else if (a >= 192 && a <= 223) {
        cout << "Class: C\nNetwork ID: " << a << "." << b << "." << c << ".0\nHost ID: " << d << endl;
    } else if (a >= 224 && a <= 239) {
        cout << "Class: D (Multicast)\nNetwork/Host ID: Not applicable\n";
    } else if (a >= 240 && a <= 255) {
        cout << "Class: E (Experimental)\nNetwork/Host ID: Not applicable\n";
    } else {
        cout << "Reserved/Loopback address\n";
    }

    WSACleanup();
    return 0;
}

Compilation & Execution:

g++ hostname.cpp -o hostname.exe -lws2_32
.\hostname.exe

IPv4 Address: 192.168.1.10

Network ID: 192.168.1.0

Practical 3(b): Dotted Decimal to 32-bit Binary Conversion

Aim: Convert a dotted decimal IPv4 address into its 32-bit binary representation.

Code (ipv4_binary.cpp)

#include <iostream>
#include <cstdio>
#include <string>

using namespace std;

int main() {
    string ip;
    int a[4];
    cout << "Enter IPv4 address: ";
    cin >> ip;

    if (sscanf(ip.c_str(), "%d.%d.%d.%d", &a[0], &a[1], &a[2], &a[3]) != 4) {
        cout << "Invalid IP address\n";
        return 0;
    }

    for (int i = 0; i < 4; i++) {
        if (a[i] < 0 || a[i] > 255) {
            cout << "Invalid IP address\n";
            return 0;
        }
    }

    cout << "32-bit binary: ";
    for (int i = 0; i < 4; i++) {
        for (int j = 7; j >= 0; j--) {
            cout << ((a[i] >> j) & 1);
        }
        if (i < 3) cout << ".";
    }
    cout << endl;
    return 0;
}

Compilation & Execution:

g++ ipv4_binary.cpp -o ipv4_binary.exe
.\ipv4_binary.exe

Practical 4(A): Dijkstra's Shortest Path Algorithm

Aim: Implement Dijkstra's algorithm in C++ to find the shortest distance from a single source vertex to all other vertices in a weighted graph.

Code (dijkstra.cpp)

#include <iostream>

using namespace std;

int main() {
    int n, a[10][10], d[10], vis[10] = {};
    const int INF = 999999;

    cout << "Enter number of vertices: ";
    cin >> n;

    cout << "Enter adjacency matrix:\n";
    for (int i = 0; i < n; i++)
        for (int j = 0; j < n; j++)
            cin >> a[i][j];

    int source;
    cout << "Enter source vertex (0 to n-1): ";
    cin >> source;

    for (int i = 0; i < n; i++) d[i] = INF;
    d[source] = 0;

    for (int i = 0; i < n; i++) {
        int u = -1, best = INF;
        for (int j = 0; j < n; j++) {
            if (!vis[j] && d[j] < best) {
                best = d[j];
                u = j;
            }
        }
        if (u == -1) break;
        vis[u] = 1;

        for (int v = 0; v < n; v++) {
            if (a[u][v] > 0 && !vis[v] && d[u] + a[u][v] < d[v]) {
                d[v] = d[u] + a[u][v];
            }
        }
    }

    cout << "\nShortest distances:\n";
    for (int i = 0; i < n; i++) {
        cout << "Vertex " << i << " : ";
        if (d[i] == INF) cout << "Unreachable\n";
        else cout << d[i] << endl;
    }
    return 0;
}

.\dijkstra.exe

Practical 4(B): Distance Vector Routing Algorithm

Aim: Implement Distance Vector Routing in C++ to compute shortest path cost and next hops across routers via Bellman-Ford updates.

Code (distance_vector.cpp)

#include <iostream>

using namespace std;

const int N = 4, INF = 999;
int cost[N][N] = {
    {0, 2, 7, INF},
    {2, 0, 3, 8},
    {7, 3, 0, 1},
    {INF, 8, 1, 0}
};

int main() {
    int d[N][N], hop[N][N];

    for (int i = 0; i < N; i++) {
        for (int j = 0; j < N; j++) {
            d[i][j] = cost[i][j];
            if (i != j && cost[i][j] < INF) hop[i][j] = j;
            else hop[i][j] = -1;
        }
    }

    bool changed;
    do {
        changed = false;
        for (int i = 0; i < N; i++) {
            for (int k = 0; k < N; k++) {
                if (i != k && cost[i][k] < INF) {
                    for (int j = 0; j < N; j++) {
                        if (d[k][j] < INF && cost[i][k] + d[k][j] < d[i][j]) {
                            d[i][j] = cost[i][k] + d[k][j];
                            hop[i][j] = k;
                            changed = true;
                        }
                    }
                }
            }
        }
    } while (changed);

    cout << "Distance table:\n";
    for (int i = 0; i < N; i++) {
        cout << "R" << i << ": ";
        for (int j = 0; j < N; j++) cout << d[i][j] << " ";
        cout << endl;
    }

    cout << "\nNext-hop table:\n";
    for (int i = 0; i < N; i++) {
        cout << "R" << i << ": ";
        for (int j = 0; j < N; j++) {
            if (hop[i][j] == -1) cout << "- ";
            else cout << "R" << hop[i][j] << " ";
        }
        cout << endl;
    }

    return 0;
}

.\distance_vector.exe
